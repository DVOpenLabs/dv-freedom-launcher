# Security

Do not post credentials, private device dumps, IP addresses, keys or exploitable vulnerability
details in public issues. Report sensitive problems to the DVOpenLabs repository owner through
an existing private contact channel. This project does not currently advertise a dedicated
security inbox or guaranteed response time.

DV Freedom Launcher is an alpha project. Development builds use the inherited development signing
configuration; they are not a production trust channel. Do not expose TV debugging to the internet.
Enable only the permissions needed for an explicitly selected feature. Personal configuration and
signing material belong outside the source repository.

The upstream project's [security guide](UPSTREAM-SECURITY.md) is retained for attribution/history;
its reporting contacts are not DV Freedom Launcher's support contacts.
