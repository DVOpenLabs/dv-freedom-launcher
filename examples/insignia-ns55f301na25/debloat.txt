# Insignia 55" Class F30 4K Fire TV (NS-55F301NA25, model AFTDCT31, codename duckie), Fire OS 7 / Android 9 (SDK 28), firmware PS7715.5585N
# Also a good starting point for other Insignia / Toshiba / Pioneer Fire TV Edition sets on Fire OS 7.
#
# Stock launcher: com.amazon.tv.launcher (and com.amazon.firehomestarter)
# Live TV app:    com.amazon.tv.livetv
#
# Apply (bash):       TV_HOST=<tv ip> tools/disable.sh examples/insignia-ns55f301na25/debloat.txt
# Undo  (bash):       TV_HOST=<tv ip> tools/restore.sh examples/insignia-ns55f301na25/debloat.txt com.amazon.tv.launcher
# Apply (PowerShell): powershell -ExecutionPolicy Bypass -File tools\disable.ps1 -TvHost <tv ip> examples\insignia-ns55f301na25\debloat.txt
# Undo  (PowerShell): powershell -ExecutionPolicy Bypass -File tools\restore.ps1 -TvHost <tv ip> examples\insignia-ns55f301na25\debloat.txt -StockLauncher com.amazon.tv.launcher
# Everything is DISABLED for user 0, not uninstalled. Comment out any line you want to keep.
#
# Known quirks on this firmware:
# - com.amazon.tv.launcher is a protected system package (`pm disable-user` throws SecurityException).
#   The custom launcher intercepts Home via HomeAccessibilityService (and mtk.intent.activity.start.name).
# - Keep com.amazon.tv.livetv, com.amazon.tv.quicksettings, and com.amazon.tv.settings.v2 enabled:
#   they provide the TIF hardware HDMI/tuner surfaces and Picture/Sound/System settings.
# - Keep com.apple.airplay.amazon.airplay enabled if you use Apple AirPlay / HomeKit.
